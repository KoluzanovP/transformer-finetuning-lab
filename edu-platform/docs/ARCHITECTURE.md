# Архитектура

## Общая схема

```
┌─────────────────────┐        REST /api            ┌──────────────────────┐
│   apps/web (Next.js) │ ─────────────────────────▶ │   apps/api (NestJS)  │
│  кабинеты 5 ролей    │  JWT (Bearer access)        │  модульная структура │
│  NotebookEditor/View │ ◀───────────────────────── │  RBAC + аудит         │
└─────────────────────┘        JSON                  └──────────┬───────────┘
          │                                                      │ Prisma
          │ localStorage: access/refresh                        ▼
          │                                            ┌──────────────────┐
          └── packages/shared (типы, роли, блоки) ──── │  PostgreSQL 16   │
                                                        └──────────────────┘
                                        Медиа: S3/R2 (dev — локальная заглушка)
```

## Backend (NestJS)

Глобально подключены два guard'а (порядок важен):
1. `JwtAuthGuard` — проверяет Bearer-access-токен, кладёт `{id,email,roles}` в запрос.
   Маршруты с `@Public()` пропускаются (login/register/refresh).
2. `RolesGuard` — сверяет роли пользователя с `@Roles(...)` на хендлере.

Каждое значимое действие пишется в `AuditLog` через `AuditService` — это и есть
«лог действий», доступный автору.

### Модули

| Модуль | Ответственность |
|--------|-----------------|
| `auth` | регистрация, вход, refresh-ротация, `/me` |
| `users` | список/создание пользователей, роли, связь родитель–ученик |
| `courses` | CRUD курсов, публикация, квота созвонов |
| `lessons` | CRUD уроков, notebook-контент, порядок, прогресс |
| `homework` | разделы домашних заданий курса/урока |
| `enrollments` | зачисление ученика, назначение учителя, квота |
| `submissions` | сдачи ДЗ: черновик/отправка/проверка/оценка/возврат |
| `comments` | Q&A в контексте урока/домашки/сдачи (треды) |
| `chat` | личный чат ученик↔учитель |
| `scheduling` | доступность преподавателей, слоты, бронирование созвонов |
| `tickets` | саппорт наставника |
| `media` | регистрация медиа-ассетов, upload-target (LOCAL/S3) |
| `analytics` | сводка автора, статистика учителя, прогресс ученика/ребёнка, аудит |

### Аутентификация и токены
- **Access** — короткоживущий JWT (по умолчанию 15 мин), подписан `JWT_ACCESS_SECRET`.
- **Refresh** — случайная строка; в БД хранится только её `sha256`-хэш
  (`RefreshToken`). При обновлении старый токен отзывается (ротация).
- OAuth (Google/VK) — модель `OAuthAccount` и переменные окружения уже заложены,
  стратегии добавляются как отдельная фаза.

## Frontend (Next.js App Router)

- `AuthProvider` (`lib/auth.tsx`) держит текущего пользователя; токены — в
  `localStorage`; api-клиент (`lib/api.ts`) автоматически добавляет `Authorization`
  и делает прозрачный refresh при 401.
- `DashboardShell` строит навигацию по ролям пользователя и защищает маршруты.
- **NotebookEditor / NotebookViewer** — редактор и просмотрщик урока: массив
  ячеек-блоков (`packages/shared/blocks.ts`), сериализуется в `Lesson.content` (JSON).
- Маршруты сгруппированы по ролям: `app/author`, `app/teacher`, `app/mentor`,
  `app/student`, `app/parent`.

## Общий пакет (`packages/shared`)
Единый источник правды для фронта и бэка: роли и их метки, enum'ы статусов,
модель notebook-блоков (`LessonDocument`/`LessonBlock`) и общие DTO.
