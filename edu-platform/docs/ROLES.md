# Роли и права доступа

Платформа использует ролевую модель (RBAC). У пользователя может быть несколько
ролей одновременно (например, учитель + наставник). Роль хранится в `User.roles`
(массив), проверяется глобальным `RolesGuard` по декоратору `@Roles(...)`.

## Роли

### Автор платформы (`AUTHOR`)
- Составляет курсы и уроки (редактор в стиле Jupyter Notebook): текст, фото,
  видео, аудио, код, тесты, разделы с домашними заданиями.
- Публикует/архивирует курсы, задаёт число созвонов на курс и длительность.
- Заводит пользователей (учителей, наставников, учеников, родителей), назначает роли.
- Зачисляет учеников на курсы и закрепляет за ними учителей.
- Связывает родителей с учениками.
- Настраивает возможное расписание созвонов каждого преподавателя/наставника.
- Видит всю статистику по учителям, наставникам, ученикам.
- Просматривает **лог действий** (аудит) каждого пользователя.

### Учитель (`TEACHER`)
- Проверяет домашние работы закреплённых учеников: оценка/балл, комментарии,
  возврат на доработку.
- Отвечает на вопросы (комментарии к урокам/домашкам, личный чат).
- Создаёт слоты и проводит созвоны, отмечает их завершение.
- Видит свою статистику и прогресс своих учеников.

### Наставник (`MENTOR`)
- Отвечает на вопросы по работе платформы через тикеты (саппорт).
- Ведёт очередь обращений, меняет статус тикета.
- Для наставника автор тоже может настраивать расписание.

### Ученик (`STUDENT`)
- Проходит уроки прикреплённого курса, отмечает прогресс.
- Сдаёт домашние задания учителю.
- Задаёт вопросы (комментарии, чат) и создаёт тикеты наставнику.
- Бронирует 30-минутные созвоны из доступных слотов учителя в пределах квоты курса.

### Родитель (`PARENT`)
- Отслеживает прогресс своих детей (учеников): прохождение уроков, оценки,
  использование квоты созвонов.
