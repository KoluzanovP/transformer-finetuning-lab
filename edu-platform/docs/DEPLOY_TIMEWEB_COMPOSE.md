# Деплой на Timeweb через Docker Compose (один стек, с телефона)

Самый простой способ: **одно приложение** типа Docker Compose из GitHub. Внутри —
три сервиса: `nginx` (единый публичный вход, порт 80), `web` (Next.js) и `api`
(NestJS). Фронт и API на одном домене → CORS не нужен и адрес API знать заранее
не требуется. Файл стека — `docker-compose.yml` в корне репозитория.

- **База данных** — управляемая PostgreSQL (Timeweb Databases).
- **Медиа** — S3 (Timeweb S3). Локальный диск в PaaS временный.
- Миграции применяются автоматически при старте `api`; первый автор создаётся из
  `BOOTSTRAP_ADMIN_*`.

---

## Шаг 1. База данных
Панель Timeweb Cloud → **Базы данных → Создать → PostgreSQL 16**. Включите
**публичный доступ**, скопируйте строку подключения (`DATABASE_URL`), допишите в
конце `?sslmode=require`.

## Шаг 2. S3 для медиа
Панель → **S3-хранилище → Создать бакет** (чтение — публичное). Запишите:
endpoint (`https://s3.timeweb.cloud`), регион, имя бакета, Access Key, Secret Key,
публичный URL бакета.

## Шаг 3. Создать приложение (Docker Compose)
1. Панель → **Приложения → Создать приложение**.
2. Источник — **GitHub**, репозиторий **`koluzanovp/edu-platform`**, ветка **main**.
3. Тип — **Docker Compose** (деплой из `docker-compose.yml`).
4. **Путь до директории проекта:** `/` (корень — там лежит `docker-compose.yml`).
5. **Путь проверки состояния:** `/api/health`
6. **Конфигурация (тариф):** берите с **≥ 2 ГБ RAM** — сборка фронта/бэка на 1 ГБ
   может не хватить памяти.

## Шаг 4. Переменные окружения
Раздел **«Переменные» → «Добавить»**, по одной:
```
DATABASE_URL=<строка из шага 1, с ?sslmode=require>
JWT_ACCESS_SECRET=<случайные 32+ символа>
JWT_REFRESH_SECRET=<другие случайные 32+ символа>
STORAGE_DRIVER=S3
S3_ENDPOINT=https://s3.timeweb.cloud
S3_REGION=ru-1
S3_BUCKET=<имя бакета>
S3_ACCESS_KEY_ID=<ключ>
S3_SECRET_ACCESS_KEY=<секрет>
S3_PUBLIC_BASE_URL=<публичный URL бакета>
BOOTSTRAP_ADMIN_EMAIL=admin@ваш-домен.ru
BOOTSTRAP_ADMIN_PASSWORD=<пароль ≥ 8 символов>
```
`NEXT_PUBLIC_API_URL` задавать НЕ нужно — фронт ходит к API по тому же домену.

## Шаг 5. Запуск
Создайте приложение и дождитесь сборки (несколько минут). Timeweb выдаст домен
`https://…twc1.net` и HTTPS. Проверьте `<домен>/api/health` → `{"status":"ok"}`.

## Шаг 6. Свой домен (по желанию)
В приложении → «Домены» → привяжите `edu.ваш-домен.ru` (Timeweb выпустит SSL).

## Шаг 7. Вход и курсы (с телефона)
1. Откройте домен, войдите как автор (email/пароль из `BOOTSTRAP_ADMIN_*`).
2. Кабинет автора → **«Курсы» → «Загрузить готовые курсы»** → появятся
   «Математика: с нуля до ЕГЭ» и «ЕГЭ: пробные варианты».
3. Потом переменные `BOOTSTRAP_ADMIN_*` можно удалить.

Дальше при каждом `git push` в `main` Timeweb пересобирает стек автоматически.

---

## Если понадобится (OAuth)
Добавьте в переменные и передеплойте:
```
OAUTH_CALLBACK_BASE=https://<ваш домен>
OAUTH_SUCCESS_REDIRECT=https://<ваш домен>/oauth/callback
GOOGLE_CLIENT_ID=… / GOOGLE_CLIENT_SECRET=…
VK_CLIENT_ID=…    / VK_CLIENT_SECRET=…
```

## Частые проблемы
- **Сборка упала по памяти** — возьмите тариф с 2 ГБ+ RAM.
- **api не стартует** — проверьте `DATABASE_URL` (публичный доступ к БД + `?sslmode=require`).
- **Медиа пропали после передеплоя** — включите `STORAGE_DRIVER=S3` (шаг 2).
- **Timeweb не находит compose** — путь до директории проекта должен быть `/`
  (файл называется `docker-compose.yml`, лежит в корне).
