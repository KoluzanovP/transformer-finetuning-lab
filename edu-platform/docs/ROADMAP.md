# Roadmap

Текущий срез — рабочий MVP: бэкенд со всеми ролями и потоками + фронтенд-кабинеты
+ e2e-тесты. Ниже — что заложено архитектурно и добавляется следующими фазами.

## Фаза 1 — MVP (готово)
- [x] Монорепо, общий пакет типов
- [x] Авторизация email+пароль, JWT access/refresh с ротацией, RBAC
- [x] Курсы, уроки (notebook-редактор), домашки
- [x] Зачисление, назначение учителя, квота созвонов
- [x] Сдачи и проверка ДЗ, прогресс уроков
- [x] Созвоны: доступность, слоты, бронирование
- [x] Комментарии, чат, тикеты наставнику
- [x] Аналитика автора, прогресс ученика/ребёнка, аудит-лог
- [x] Кабинеты всех 5 ролей, seed, e2e-тесты

## Фаза 2 — Медиа и загрузки
- [x] Реальные presigned-загрузки в Cloudflare R2 / S3 (driver=S3) + LOCAL на диск
- [x] Загрузка файлов прямо из notebook-редактора (фото/видео/аудио)
- [ ] Транскодирование/превью видео, ограничение доступа к приватному медиа

## Фаза 3 — OAuth и уведомления
- [x] Вход через Google и VK (OAuth-flow + связывание `OAuthAccount`, dev-mock)
- [x] In-app уведомления (события ДЗ, созвонов, тикетов) + колокол в интерфейсе
- [ ] Email-уведомления (транспорт SMTP)

## Фаза 4 — Созвоны глубже
- [x] Генерация слотов из `AvailabilityRule` на N недель вперёд
- [ ] Интеграция Zoom/Google Meet API (авто-создание встреч)
- [ ] Напоминания и учёт часовых поясов

## Фаза 5 — Оплата (отдельная фаза по решению заказчика)
- [ ] ЮKassa / Stripe: покупка курсов и пакетов созвонов
- [ ] Биллинг, чеки, возвраты; точки расширения в `Course`/`Enrollment`

## Фаза 6 — Качество и эксплуатация
- [x] Playwright e2e для веба (smoke-сценарии)
- [x] CI (GitHub Actions): сборка + миграции + unit/e2e + web build
- [x] Базовая безопасность (helmet, CORS, rate-limit, RBAC, анти-эскалация) — см. SECURITY.md
- [ ] 2FA/TOTP для персонала, CAPTCHA на регистрации
- [ ] Роли-редакторы прав, аудит-экспорт, метрики и алерты
- [ ] Группы/потоки учеников (если понадобится групповой формат)
